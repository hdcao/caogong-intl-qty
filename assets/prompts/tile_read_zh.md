# 切块精读指令（中文版）

> 用法：把本文件整段作为提示词，连同 `manifest.json` 里指定的**一块** tile 图一起给出。
> 一次只读一块，不要一次给多块——多块同时读会互相串行号，且无法定位错误出在哪一块。
> 输出必须是 JSON，字段见 §四。**不要输出散文式描述**。

---

## 一、这张图是什么（让你先建立边界）

- 这是**整张工程图纸被切下的一块**，不是完整图纸。
- 所以你看到的构件可能只是一部分，**不要根据这一块推断整张图的总数**。
- 块与块之间有 15% 重叠，同一构件可能在相邻两块里都出现——**这是正常的，不要当成重复构件**。

## 二、只数这些（正向清单）

1. 构件本体：梁 / 柱 / 板 / 墙 / 桩 / 承台 / 盖梁 / 管道 / 设备 / 灯具…
2. 图面上的**明确数字**：尺寸标注、标高、间距（`@` 后数字）、编号、型号、数量
3. 集中标注的每一行（多行竖排的，一行一行读，不要跳过任何一行）
4. 材料代号与规格（`HA` / `FE` / `Ø` / `C25` / `IPE` / `HEB`…）
5. 轴线圆圈内的编号（只用于定位，不计数量）

## 三、不要数这些（负向清单）

- ❌ **图例页/符号说明页里的符号**——那是示意，不是实际安装的构件
- ❌ **标签块、文字标注框本身**（如 `DOOR TAG`、引线框）——它们标识构件，本身不是构件
- ❌ 同一构件的多个视图（平面画一次、剖面又画一次）——**在一块内只按一种视图计一次**
- ❌ 图签、会签栏、图纸说明里的文字
- ❌ 被切块边界截断、无法判断归属的构件——记到 `truncated` 里，不要猜

## 四、输出格式（严格 JSON，不要加注释和解释）

```json
{
  "tile": "<manifest 里的 tile 路径>",
  "page": 1,
  "drawing_type": "配筋图 | 布置图 | 合图 | 剖面 | 立面 | 明细表 | 图例页 | 无法判断",
  "axes_visible": ["A", "B", "C"],
  "objects": [
    {
      "type": "梁 | 柱 | 板 | 墙 | 桩 | 承台 | 盖梁 | 管道 | 设备 | 灯具 | 其他",
      "label": "<图面上的编号或名称，照抄不要翻译>",
      "spec": "<规格：断面/直径/型号，照抄>",
      "quantity": 10,
      "quantity_kind": "count | length_mm | area_mm2 | volume_mm3 | spacing_mm",
      "nearest_axes": "B-C / 3-4",
      "center_px": [1240, 860],
      "confidence": "clear | fuzzy | unreadable",
      "evidence_text": "<图上原字，逐字照抄，包括上下标与撇号>"
    }
  ],
  "dimensions": [
    {"text": "3600", "value": 3600, "unit": "mm", "what": "层高", "center_px": [800, 420], "confidence": "clear"}
  ],
  "truncated": ["被边界截断、归属不明的对象描述"],
  "notes": "本块特有的情况（如图签、大样、重复出现）"
}
```

**字段纪律**：

- `confidence` 三档：`clear` 清晰可读 / `fuzzy` 略糊或位于块边缘 / `unreadable` 难辨
- `center_px` 是**本 tile 图内的像素坐标**（左上角为原点），必须给，不许写"见图"
- `evidence_text` 必须逐字照抄原图，**含撇号与下标**（`A'` 不能写成 `A`，`A₁` 不能写成 `A1`）
- 读不准就写 `unreadable` 并保留 `center_px`，让人去复核——**不要为了让 JSON 完整而编一个数**

## 五、三句压舱话（每次都要遵守）

1. **禁止估算。** 图上没有的数字不要给。宁可返回空数组，也不要"大约""差不多"。
2. **不要遗漏任何一个。** 同一块里出现 30 根一样的桩，就写 30，不要抽样、不要"以此类推"。
3. **若来自大样图（DÉTAIL / DETAIL），只数大样内的数量**，并注明"需乘重复次数"，
   **不要**自动与平面图的数量相加——重复次数必须另行在平面图点算。

## 六、读不出来怎么办

返回 `objects: []` 且在 `notes` 写明原因（字太小 / 转曲 / 被边界截断 / 图例页）。
**空数组是合法答案，"猜一个数"不是。**
