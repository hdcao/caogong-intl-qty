# 硬规矩与停止条件（SKILL.md 执行规范的详细条款）

## 硬规矩

**禁止**：

- **H01** 编造图纸上没有的数字充数
- **H02** 把假设值写成图读值（两者必须可区分）
- **H03** 在门禁报红时放行并声称完成
- **H04** 用字符串存在性检查冒充数值防线
- **H05** 口径不明时按单一算式硬算
- **H06** 用"大致相当"放过超过阈值的差异
- **H07** 只核合计数（**合计对不等于明细对**）
- **H08** 只核最后一个合计行（**表里有几个小计就要查几个**）
- **H09** **同一实物开两个计量入口**
- **H10** 把可选项（OPTIONS）计入基础方案总价
- **H11** 在单位量纲没查清前就乘除归一
- **H12** **用「幅×跨×片×端」推算支座/伸缩缝**（必须直读专用表）
- **H13** 未验证前提就施加批量变换
- **H14** 把门禁的 exit 1 当成有效结论（**exit 2 是门禁没跑或崩了**，不是通过也不是不通过）
- **H15** **分母为 0 还写「通过」**（检查 0 行 = 未运行）
- **H16** **单位不在词表就当没这回事**（词表外 = 未校验，不是通过）
- **H17** **改了表不更新基准**（`verified_at` 不动 → 门禁拿旧基线开绿灯）
- **H18** **跨表映射只登记几行就宣称"无脱钩"**
- **H19** 建册未 `CONFIRMED` 就出交付版
- **H20** **（v2）用一个构件的参数外推同项目其他同类构件**（逐座判定）
- **H21** **（v2）引用他专业的实测数字/修正幅度**（跨专业外推无意义）
- **H22** **（v2）单位列与口径声明量纲矛盾**（A02 型事故，唯一防线是 G-DW）
- **H23** **（v2）复核人直接改写读数而不改签名栏**（改写即成为新责任人）
- **H24** **（v4）把图例/符号示意页的符号数当成安装量**（实测：MEP 虚报 4429，真实 3880）
- **H25** **（v4）把标签块/文字标注块当成构件计数**（实测：门标签 19369 vs 真实门 1879）
- **H26** **（v4）按文件数计量同代复本**（同 sig 只计 1 张；四图号族 4 倍虚报）
- **H27** **（v4）把损耗写进合同计量面积**（净量/损耗/采购/报价必须分列）
- **H28** **（v4）体系乘数未登记就出全楼合计**（乘数错 → 整套 BOQ 等比例错）
- **H29** **（v4）测量策略卡还有 TO_BE_CONFIRMED 就出交付版**
- **H30** **（v4）只统计 top10 图层就出图层合计**（长尾图层会被漏掉，实测少计 63%）
- **H31** 代人签发
- **H32** **（v4.6）对可数构件输出约数**——能逐个点数时禁止写"约 XX""大概""左右"。
  数不准就写 `1876+3?` 这种结构化写法（已确认 + 待定点数），并在 `note` 给出待定点**具体位置**；
  **"约"在计量成果里等于未完成**。按间距/乘数推算的不可数项不受本条约束，改按停止条件 7 走推定层
- **H33** **（v4.6）跨图参数冲突未裁决就出下游量**——同一参数在两张图上给出两个值，未定版前
  不得用任一值驱动交付量。但没有"不打断"的例外，也没有"照算一个值、不写冲突"的余地：
  先做 `SENSITIVITY_ONLY` 粗量试算（两值各算一遍、明确标注不作交付），差值 <5% 按较新版继续、
  5%~15% 双值并列并挂 OI、>15% 才停。**10% 不是神数**——照抄 FIDIC 议价门槛会出时序悖论
  （要判是否 10% 得先算量，而算量又被禁止），阈值最终以合同计量办法为准
- **H34** **（v4.6.1 修订）把无法回图复核的读数当作交付证据**——判据是**能不能唯一复原到图面位置**，
  载体不限于 tile：tile 坐标（含 tile 内坐标）、或「图号 + 轴网区格 + 局部截图 + 图上像素坐标」
  任一，只要另一人能据此回到同一处，就算可复核。原来的写法把 tile manifest 当成唯一形态，
  现场看蓝图/PDF 的人做不出 manifest，于是正规记录反被判 weak——**把实现手段当判据是自缚**
- **H35** **（v4.6.1）在比例失真图上做量测**——图签含 `NOT TO SCALE` / `SANS ÉCHELLE` / 不按比例，
  或图框/比例尺条尺寸与标准幅面对不上（A0 应为 841×1189 mm）时，**禁止任何图面量测**，只能读标注。
  整页等比缩放（A0 缩印 A3、扫描重采样、微信转图）会让"双校准"两个参照同时同比例偏移，
  互证 100% 通过而全图偏 29%（面积偏 50%）——双校准挡不住它，只有图框/比例尺条挡得住
- **H36** **（v4.6.1）同一物理构件跨专业重复计量或双向都不计**——建筑图画了柱墙板、结构图也画，
  MEP 图与结构图都画套管洞口。**同一构件只允许一个计量 owner**：几何以结构图为准、做法以建筑图为准，
  套管与洞口必须指定单向归属。两边都算 → 混凝土虚增；两边都不算 → 洞口补强漏项
- **H37** **（v4.6.1）把暂列金额（Provisional Sum）的量计入合同计量量**——PS 是**金额条目**，
  不是"按图估算的量"。`undefined provisional sum` 只能按工程师指示使用；任何"按图估算后填进暂定项"
  属推定层，须与 `contract_measured` 分列，否则投标时白担风险、结算时量价双错
- **H38** **（v4.6.1）用投标单价反推变更量**——变更量必须用**与原合同同一套计量规则、同一套证据标准**
  重算，变更前后分列可比。用原单价倒推量，会把"量差"洗成"价差"，索赔在评审时站不住。
  措施费与工期影响不在算量范围，但必须提示合同经理（PG-04）

**条款引用方式**：出审阅意见、写 RFI、记故障案例时，直接引 `H12` 这样的编号，
不要写"按硬规矩第几条"——编号化的唯一目的就是能逐条对账。

## 停止条件

出现以下情况**停下并说明**，不要自行推进：

1. 图纸关键参数无法确认，且无规范或惯例可依
   （"关键"= 该参数变动会改变**分部量 ≥10%** 或驱动 ≥3 个下游量；说不出这两条就不算触发）
2. 门禁报红，且**同一红项按判据逐条排查过一遍仍无法归因**（须写明排查了哪几条判据）
3. 交叉复核判为同源假通过（≥90% 项 rel 恰为 0.000%），且无法回图重建参数
4. 需要登录、付费或授权才能获取的资料
5. 未验证前提就想施加批量变换（归一/重写/插行）
   （"验证"= 抽样 ≥3 处原图核对 + 记录在台账）
6. **（v2.1）结构体系未闭合却要出量差**——先解决体系，再谈数。
   体系 8 项必答，**答不全即触发本条**（逐桥/逐座）：

   | # | 必答项 | 合格判据（缺一即"判不出"） |
   |---|---|---|
   | 1 | 上部梁型与单梁断面 | 断面面积由 ≥3 个标注尺寸乘加得出，算式写进口径声明；不得直接引用"0.75 m²"这类无推导面积 |
   | 2 | 梁片数与横向节距 | 片数由两条**独立**证据闭合（横断面块数 / 支座数÷2 / 业主清单 U 数）；节距链 Σ 与桥面净宽差 ≤1% |
   | 3 | 横向宽度链 | 桥面宽 / 盖梁长 / 台身宽 / 承台宽 / 桩群外边距逐对可解释；任一相邻差 >0.30 m 必须写明构造原因，写不出即判不出 |
   | 4 | 纵向跨径与梁长 | Σ跨径 = 桥长 ±0.1%；梁长−跨径的扣减值须有标注或图证，**不得在 −0.20/−0.30 之间"选一个"** |
   | 5 | 墩柱形式 | 柱式/墙式、每墩柱数、柱径、**柱高的起算面与终止面**必须写明，且与承台/盖梁量不重叠 |
   | 6 | 基础形式与桩参数 | 桩基/扩大基础已定；桩径、桩数、**桩长起止标高**、持力层齐全。仅单点"20.00"标注用于全部支承 → 判不出 |
   | 7 | 竖向高程链 | Σ分量 = 总差（±10 mm）**且**各分量区间两两不重叠 |
   | 8 | 单幅/双幅与跨分部归属 | 平面有行车道标注或半幅线；道砟/轨道/防撞墙归属写死 |

   **解除条件**：给出被触发项的补证（图号+图面位置 / RFI 编号）并入建册。
   8 项未全部留痕前，只允许出"单构件试算"，**不得出全桥合计、不得与业主清单做量差结论**。
7. **（v2.1）某个量的唯一来源是惯例/经验**（含钢率、按"每支承 1 根"推算的基础、按间距推算的支吊架），
   且图纸与规范均无依据 → **不停止，但必须降级处置**：
   ① 单列"推定层"，不与图读行混排；② 口径声明写 `推定(依据+系数+区间)`，**禁止写"图读值/图纸确认"**；
   ③ 挂 RFI 编号进假设台账（假设人+日期必填）；④ **不得进入承诺量、不得用于与业主清单做量差结论**；
   ⑤ 系数无出处者，按硬规矩拒绝落数。
   **例外（仍须停）**：该推定值一旦被推翻会改变**体系结论**（桩基→扩大基础、单幅→双幅、预制→现浇）时，
   回到第 6 条，不得以推定方式推进。
8. **（v4）体系乘数或版本冲突未裁决**——双塔/多栋/重复区段的乘数没登记来源，
   或同一构件在两个版本间数量/尺寸不一致且未按文件版本时间定版：
   → **不得出全楼合计、不得与业主清单做量差结论**。
   允许出的：单张图、单个区段、单个构件的量，且必须标注"未含体系乘数"。
   解除条件：乘数与依据写入测量策略卡 `system_multiplier`，版本裁决写入 OI 台账。

停下时必须说明：**是哪一条** + **需要什么输入才能解除**。

## v4.6.2 新增硬规矩（H39~H42）

> 背景：本项目 21 轮迭代，同类错误反复发生。归因确认不是知识不足，
> 而是「输入未消化」「门禁只验内部自洽」「规则写了不保证执行」三个机制缺口。
> 以下四条把它们变成可阻断的规矩。

### H39 输入未消化不得出量

`input_digest.py verify` 非 0 时，只能做**探索性试算**，成果标 `DRAFT`，
且交付物首行必须写明「本次为探索性试算，未完成输入消化」。
**未消化的表现**：说不出「算哪些 / 按什么算 / 拿什么算 / 算到什么程度」四问，
或答了但给不出出处（页码/图号/条款号）。

### H40 消化结论必须带出处，且不得由 AI 代签

`answer` 写「按合同」不合格，须写「标书 Vol.2 p.147 §3.4」。
`source` / `by` 均为必填；`by` 为 `AI`/`TBD`/空白一律拒绝写入。
**无出处的消化等同于没消化。**

### H41 外部数据源必须先做语义登记，再参与换算

任何外来清单/信息表，其数值列必须经 `gate_source_semantics.py verify` 确认：
列义（quantity/dimension/flow/rate…）、单位、以及 `value_basis`（net/gross）。
**未登记语义的数值列不得进入任何工程量换算。**

### H42 净量原则：一律按不含富余系数的净量出数

外部清单若含损耗/富余/超挖/搭接系数，必须先 ÷ 系数归一。
本项目核查出的 ×1.05 系数据此归一后，才能与图纸净量或其它方清单比较。
含系数出数会造成固定比例的系统性假差异，把真实量差淹没。

## H43 门禁执行凭证：没有凭证不得宣称"全部门禁通过"

`gate_execution_receipt.py verify --strict` 非 0 时：

- **不得**在任何交付物中写「全部门禁通过」「检查全部通过」；
- 汇总只能写三栏：`通过 N 项 / 未运行 K 项 / 待确认 M 项`；
- required 门禁缺失 = 没跑，**不许默认通过**；
- `rows_checked == 0` = 没检，不是通过；
- `rows_checked < rows_expected` = 分母缩水，剩余判据未被验证。

**历史依据**：某轮 G-X0 的规则/门禁/脚本三样齐全，仍写出「交叉检核通过（独立代码路径）」，
实为自建对照表未跑脚本，13 项全 0.000% 假通过漏网。
**规则的有效性不取决于写得多好，而取决于"没跑就出不了交付物"。**

## v4.6.3 新增硬规矩（H44~H48）：表外缺席

> 来源：`ccj-qty v3.3.0`（该技能 v3.0.0 曾吸收本技能 v4.0.1 的八项口径层机制，
> 之后独立发展）。本组只吸收它分化后独有、本技能确实没有的增量。
> **背景**：v4.6.2 补的 G-SRC 抓「读了错的东西」；但**漏掉的东西不在表内，
> 表内自洽永远查不到**——这是「门禁只验内部自洽」缺口的另一半。

### H44 表外缺席必须过 G-OFF

交付前 `gate_off_table.py check --strict` 须 exit 0，覆盖四类：
**COV** 图册页数/空白页 · **PAIR** 必搭配件缺项 · **RATIO** 含量比率带 · **OI** 敞口四态。
`G-OFF` 已列入 G-RUN 三档 required 清单，**没跑 = 没通过**。
实测教训：37 张里 16 张空白的册，那一册的量不是算错，是根本没有算，18 道门禁全绿。

### H45 「未核」不等于「通过」

每册须登记 `pages_total` + (`pages_valid` 或 `blank_pages`)；
未登记记 WARN（strict 下 FAIL）并明写「未核」，**绝不记 PASS**；
范围内无图纸直接 exit 2（未运行）。缺页时须先定性该册覆盖的分部是否在算量范围内，
再决定出不出量——直接跳过等于把整册当成不存在，而报告上看不出任何异常。

### H46 比率带只能来自项目声明，且只指路不定性

`ratio_bands` 必须带合法 `declared_by`（填「常规/经验/一般情况」等同没声明，**AI 不得自拟带**）；
未声明就出 INFO「未校验」，明写跳过，**不静默通过**。
带外只报「**分母疑漏｜也可能是分子重复计**」，由人下结论，脚本不替人裁决。
**本技能不内置任何基准带**——把惯例值变成判据，正是 ×1.05 系数误判与
「填方误用挖方表沙丘 6:1（−152,100 m³）」的来路。

### H47 敞口只四态，「挂账」即未判态

状态只允许 `CLOSED` / `SCOPED` / `RFI` / `EXTERNAL`；写「挂账」「待核」「持续跟踪」= 没写。
`CLOSED` 须有图号级 `basis`（「已核/已确认/无误」是占位词）；混态必须拆条。
**凡归 RFI/EXTERNAL 必须回答「下一轮读图能不能解决」，答「能」的退回待办而非 RFI。**
僵尸标记（敞口已 CLOSED 但「推定区/不得进报价/暂列」开关还开着）一律 FAIL——
已核实的量不得被排除在报价外。隔离类词判 FAIL、说明类词只 INFO，防一刀切误报。

### H48 取值层级、注记落地、工法未定、状态码封顶

- **图注 > 图面实测 > 尺寸链推算**：实测只补缺或校核（差 >2% 挂 conflict+RFI），
  **不得用实测覆盖图上已有注记**。
- **注记必须落地**：关键注记只能「采纳 / 降级进推定区 / 证明属他构件」三选一；
  **禁止「按另一个数出量 + 同时挂 RFI」**——挂账不是免责，是把错数留在表里过夜。
- **工法未定不出量**：`ambiguous` / `insufficient_info` / `undetermined` 时主体量可出，
  **措施量与工法派生量一律不出**；不得自造库里没有的 `method_id`。
  （只吸收原则，不搬 368 条工法库：其中仅 41 条可判定，且本项目 21 轮无工法类错误。）
- **图册状态码封顶**：`IFT/IFA/IFR/IFP/SD/DD/APS/APD` → 「图读·尺寸链」；
  `IFC/CD/EXE` → 「图读·标注」；`AB/AS-BUILT` → 标注且须实测互证。
  **看不到状态码就挂 RFI，不许默认按 IFC**（见 `references/off-table-gaps.md` §4）。
