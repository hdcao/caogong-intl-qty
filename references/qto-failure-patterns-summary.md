# 算量严重失误模式：主入口摘录

## 一句话提醒

二十类大事故——**把纵向当横向**（−39.4%）、**双幅只看一排**（少算一半）、
**公式错位一行**（总额只差 0.41% 但逐行全错）、**跨表脱钩**（两侧各自都对，
中间断了 5585 万）、**OPTIONS 混进基础报价**（2390 万）、
**同表两套量纲**（m³ 与 m³×10）、**一物两个计量入口**（墩身 360 + 墩墙 420，
真值 210）、**只查最后一个合计行**（9 个小计错 8 个，门禁全绿）、
**基线不随表更新**（门禁全绿，但它读的是旧值）、
**梁间距当梁宽**（+131%）、**背墙厚度当台身厚度**（−86%）、
**跨列量纲矛盾**（单位 SM 而口径写 m³，躺两轮）、
**同类构件套同一参数**（逐座设计壁厚并不相同）——
**没有一个是算错**，全都是"算的是另一个口径"、或者"根本没算到那儿"，
而表面上每个数都"有出处"。

**（v4）新增四类同样"看不出来"的**：
**把符号示意页当安装量**（MEP 虚报 4429，真值 3880）、
**把门标签块当门**（19369 vs 1879）、
**把同代复本当多张图**（四图号族 4 倍）、
**把损耗写进计量面积**（材料需求污染合同计量量）。
这四类都有共同特征：**每一行都指向真实图元，合起来就是错的**。

门禁就是专门抓这一类。而门禁自己也会写错：
本技能的判据库里有**五版被注入验证推翻的判据**
（跨数量级、中位数偏离、绝对区间、整行文本扫描、口径单列检查），
留痕在 `gate_unit_consistency.py` 与 `gate_dimension_wording.py` 的注释表里——
**判据强度只能靠注入验证，写完觉得"够严"不算数**。
