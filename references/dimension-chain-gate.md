# 尺寸链闸门：把图纸尺寸链写成断言

**什么时候读**
- 读图阶段结束、开始落数**之前**——先把读出来的尺寸关系写成判据，再算量
- 任何"根数 / 片数 / 道数 / 层数"的结论要进表之前
- 同一构件量了多个剖面、要取代表值之前
- 交付前：想知道"这个数凭什么可信"，而不只是"这个数算得对不对"

配套脚本：`scripts/chain_check.py`（`Chain` 类 + CLI spec 模式 + `selftest`）。

---

## 一、为什么单靠"算对"不够

算术错 Excel 会报，公式错门禁会报。**尺寸链读错，什么都不会报**——因为算得完全正确，
只是把关系读错了，结果是一个"看起来很合理"的数。

2026-10-29 阿尔及利亚 ANESRIF 铁路桥（VIADUC PK295+300，APS 阶段）实测：

- 第一版交出 **17,306 m³**；第三方成果 **15,631 m³**；差 11%。
- 差 11% 时双方都倾向于认为"互相印证、可以交付"。
- 回图复测后发现 **6 处实质错误**：桩基+墩柱高估约 3,456 m³，桥面板+桥台低估约 1,601 m³。
- **两个数接近，是错误互相抵消，不是准确。**

> 元规则：**总量对不上，一定是哪里错了；总量对上了，什么都不能证明。**

六处错误没有一处是算错：

| # | 当时读成 | 图上真相 | 性质 |
|---|---|---|---|
| E1 | 桩 8 根/墩（4 排 × 2 列） | 12 根（3 列 × 4 排） | 数量 |
| E2 | 墩身双肢墙 2 × 4.35 × 1.60 | 3 根 Ø2.00 圆柱 | 构件形式 |
| E3 | 墩高 9.08 m | 5.00 m | 基准与扣减 |
| E4 | 盖梁高 1.50 m | 2.00 m | 单值 |
| E5 | 桥面板只算梁间带 3.54 m | 全宽 12.90 m | 构件范围 |
| E6 | 主梁 9 片/跨、断面 0.948 | 10 片/跨、梁身 0.725 | 计数口径 + 取样 |

三个共同毛病：**只看了数，没看数的关系。**

- `4.35` 是柱**中心距**，不是墙宽；`1.60` 是**边距**，不是墙厚。位置错一格，构件形式就认错。
- `0.69 + 9 × 1.28 + 0.69 = 12.90` 里那个 **9 是间隔数**，片数是 10。链是闭合的，只是被读成了梁数。
- 5 个剖面（0.725 / 0.725 / 0.861 / 1.244 / 1.187）直接平均得 0.948。其中 D-D/E-E 是**横隔梁处的实体断面**，不是梁身——平均等于把横隔梁摊到每片梁上。

## 二、三类判据（只需三类，覆盖上述全部）

| 类型 | 形式 | 抓什么 | 本桥实例 |
|---|---|---|---|
| **闭合** `eq` | Σ分段 = 总尺寸 | 数量数错、漏项、双重扣减 | 桩位横向 `1.20+3.60+3.60+1.20 = 9.60`；墩链 `2.20+5.00+2.00+0.283+2.00+0.30+0.80 = 12.583` |
| **可行性** `le` / `ge` | 子项 ≤ 包容尺寸 | 几何上装不进去 | 4 排跨度 13.20 必须装进承台横长 13.20；塞进 9.60 立刻报 |
| **同质性** `homog` | max/min ≤ 限值 | 把不同性质的剖面混在一起平均 | 梁身 0.725/0.725 离散度 1.00 通过；混入 1.244 后 1.72 > 1.10 报 |

**为什么"可行性"必须单独一类**：E1 的错误在于 4 排 × 3.60 = 10.80 m 装不进 9.60 m 承台。
闭合判据当时是绿的——因为闭合判据比较的是"链算出来的数"和"图上标的数"，
而两者都被读错了，一起错就一起对。**只有把子项和包容尺寸直接比，才能发现装不进去。**

**为什么"同质性"必须显式判**：平均值本身没有错，错在"把不同性质的东西放在一起平均"。
判据是 max/min，不是标准差——离散度对单个离群值敏感，正是要它敏感。

## 三、怎么写（脚本用法）

```python
from chain_check import Chain

C = Chain("VIADUC PK295+300")

# 闭合：链上的分段必须加得起来
C.eq("桩位横向(3列)", 1.20 + 3.60 + 3.60 + 1.20, 9.60, note="PLAN 墩位平面链")
C.sum_eq("盖梁宽链", [1.60, 4.35, 4.35, 1.60], 11.90)   # 漏一段就报

# 可行性：子项必须装得进包容尺寸
C.le("桩位纵向可行", 1.20 + 3.60 * 3 + 1.20, 13.20, note="装不进去就是数错了")
C.le("柱组含于盖梁", 3 * 2.00 + 2 * 2.35, 11.90)

# 同质性：不同性质的剖面禁止平均
C.homog("断面同质性", [0.725, 0.725], limit=1.10)

# 更好：先按判别量分组，再查组内同质 + 组间单调（见第七节）
C.classify("断面性质", measure=SEC, ratio=WEB_RATIO,
           cuts=(0.50, 0.90), labels=("梁身", "过渡", "填实"))

BAD, WARN = C.verify(strict=True)     # 模块级执行 ⇒ 导入即校验
```

`level="warn"` 的判据只登记不阻断（例如某个标高读数可疑、但不影响工程量）。
**分级是刻意的**：把所有判据都设成阻断，遇到数据瑕疵就只能整条流水线停摆；
全部设成 warn，则等于没有闸门。阻断项必须为 0，待核项必须出现在交付说明里。

### 命令行（不想写 Python 时）

```bash
python scripts/chain_check.py run --spec checks.json --out out/
python scripts/chain_check.py selftest
```

`checks.json`：

```json
{
  "title": "桥墩尺寸链",
  "checks": [
    {"name": "桩位横向", "kind": "eq", "lhs": "1.20+3.60+3.60+1.20", "rhs": "9.60",
     "note": "PLAN 平面链"},
    {"name": "桩位纵向可行", "kind": "le", "lhs": "1.20+3.60*3+1.20", "rhs": "13.20"},
    {"name": "断面同质性", "kind": "homog", "values": [0.725, 0.725], "limit": 1.10}
  ]
}
```

`lhs`/`rhs` 只接受**数字与四则运算**。不直接 `eval`——那等于让一份配置文件拥有任意代码
执行权；变量名一律拒绝，强制把数值来源写在 note 里。

### 退出码

| 码 | 含义 |
|---|---|
| 0 | 通过（判据 > 0 条，阻断 0，判据自身无错） |
| 1 | 有阻断项，或判据自身写错 |
| 2 | 未能执行（spec 解析失败 / checks 为空）——**不代表检查结论** |

## 四、三条落地规矩（比脚本更重要）

### 4.1 导入即校验，不要"最后再查一遍"

把 `verify(strict=True)` 放在模型模块的**模块级**：

```python
_GATE_BAD, _GATE_WARN = C.verify(strict=True)   # 模块级
```

任何 import 这个模块的下游脚本（台账 / 算量表 / 报告）都会在导入时**立刻失败**。
改错一个常量，整条流水线出不了表。

反例（本桥第一版就是这样）：闸门写成 `if __name__ == "__main__":` 里的一次性检查，
主流程根本不经过它。**没有被接进主流程的检查，等于没写。**

### 4.2 常量唯一来源，链里禁止写字面量

```python
# 错：改 CAP_H 时链不联动
C.eq("墩链", 2.20 + 5.00 + 2.00 + 0.283 + 2.00 + 0.30 + 0.80, 12.583)

# 对：链里只引用常量
C.eq("墩链", FOOT_H + COL_H + CAP_H + BRG_H + BEAM_H + SLAB_T + BALLAST_H, FSR_OFFSET)
```

本桥的回归测试当场抓到了这个缺陷：把盖梁高从 2.00 改成 1.50 做注入，
`墩链` 仍然通过——因为链里硬写了 `2.00`。**判据看起来在守，实际守的是另一个数。**

同理，范围口径、推翻后处置这类文字也不要在多个文件里各写一份：
本桥 v1 的 `build_qty.py` 已改对，`build_xlsx.py` 里还硬写着"108 根 / 9 根/跨 / Σ墩高 108.76m"，
表里那一列就一直是错的。**单一来源不只是数值，也包括口径文字。**

### 4.3 每条判据都要有一条注入用例

`chain_check.py selftest` 把本桥 7 类历史错误逐一注回模型，断言每条都被拦住。
新增判据时同时加一条注入用例——否则你无法区分"判据在工作"和"判据永远为真"。

```
基线：通过
  [拦住] 主梁片数 10→9（把 9 个间隔当 9 片梁）      -> 梁片数闭合、梁系铺满桥面
  [拦住] 桩 3 列→2 列（v1 的 4排×2列=8 根）          -> 桩位横向(3列)、桩根数
  [拦住] 墩柱径 2.00→4.35（把中心距当柱径）          -> 柱组含于盖梁
  [拦住] 盖梁高 2.00→1.50（v1 的取值）               -> 墩链
  [拦住] 桥面板宽 12.90→3.54（只算梁间现浇带）       -> 桥面板为全宽
  [拦住] 把 4 排塞进 9.60 那个方向                    -> 桩位纵向可行
  [拦住] 梁断面组混入横隔梁断面（5 面均值）          -> 断面同质性
7/7 类历史错误被闸门拦截
[OK] 判据自身写错被识别为 spec 错误（不冒充「抓到问题」）
[OK] 空判据集不判通过（分母为 0）
[OK] classify 按腹板宽/底翼缘分档：梁身 ['A-A','B-B'] / 过渡 ['C-C'] / 填实 ['D-D','E-E']
[OK] 判别量测错（全同值）→ 报警：梁身组同质、过渡组非空、填实组非空
```

**基线必须先绿**：干净模型跑不过时，下面每一条"拦住"都不成立——那只是模型本来就有错。

## 五、与既有门禁的分工

| 层 | 谁在管 | 回答的问题 |
|---|---|---|
| 算得对不对 | Excel / `gate_sheet_formula` | 公式有没有错位、小计区间对不对 |
| 数从哪来 | `gate_drawing_basis` + `basis.json` | 这个数与图纸读数是否一致 |
| 口径一致否 | `gate_scope_declaration` / `gate_dimension_wording` | 单/全、单侧/两侧有没有写清 |
| 表间一致否 | `gate_cross_sheet` | 明细 / 汇总 / 校核三处是否脱钩 |
| **关系读对没** | **`chain_check`（本文件）** | **这些数之间的关系成立吗** |

前四层都绿而第五层红，是完全可能的——本桥第一版就是。**它们是并列的五层，不是替代关系。**

## 六、适用范围

- **该用**：有明确尺寸链的构件——桩基（列×排）、墩柱（净距+直径）、盖梁（宽链）、
  梁系（片数+间距+铺满）、板（全宽）、层状构造（Σ层厚 = 总厚）。
- **不该硬套**：链上没有可闭合关系、只能靠指标的项（预应力束重、含钢率）。
  这些走 `evidence-grading.md` 的估算档，不要为了"凑一条判据"编一个假等式。
- **同质性判据的前提**：剖面的"性质分类"必须先做对。把梁身和横隔梁都归成"梁断面"，
  判据只会告诉你"离散度大"，不会告诉你"哪个不属于这一组"。
  **但分类不等于只能靠人看**——见第七节，分类本身是可以量出来的。

## 七、断面性质：不靠看，靠量腹板宽

「同质性」判据要求先分类，很容易被理解成"分类只能人工判断，所以这条判据有前提漏洞"。
不是。**分类本身就是一个可测量的量**，只要选对测量对象。

### 7.1 为什么不能用面积分类

面积是待判定的结果，用它分类是循环论证：你看到 1.244 和 0.725 差得多，才知道它们不同类——
但这正是判据要告诉你的。而且面积差多少才算"不同类"，本身没有物理阈值。

### 7.2 正确的测量对象：腹板宽 / 底翼缘宽

T 梁断面的性质由**腹板是否被填实**决定，这直接反映在腹板宽度上：

| 剖面 | 腹板宽（30~70% 高） | 底翼缘宽 | 比值 | 性质 |
|---|---|---|---|---|
| A-A | 25.7 cm | 60.4 cm | 0.43 | 梁身 |
| B-B | 25.8 cm | 60.4 cm | 0.43 | 梁身 |
| C-C | 35.7 cm | 60.4 cm | 0.59 | 过渡（腹板加宽） |
| D-D | 60.4 cm | 60.4 cm | 1.00 | 横隔梁（填实） |
| E-E | 59.4 cm | 59.4 cm | 1.00 | 梁端块（填实） |

阈值：`< 0.50` 梁身 / `0.50~0.90` 过渡 / `≥ 0.90` 填实。
**这个比值是物理量，不是约定**——腹板填实到与底翼缘同宽，比值必然是 1。

### 7.3 怎么量

用 `get_drawings()` 取该剖面的闭合轮廓，在 30%~70% 高度处做水平扫描线，
求与多边形边的交点，取 `max(x) - min(x)`：

```python
def width_at(pts, y):
    xs = []
    for i in range(len(pts)):
        a, b = pts[i], pts[(i+1) % len(pts)]
        if (a.y <= y < b.y) or (b.y <= y < a.y):
            xs.append(a.x + (y-a.y)/(b.y-a.y)*(b.x-a.x))
    return max(xs) - min(xs) if xs else None
```

注意：这类图纸的尺寸数字常被炸成矢量曲线，**文本层取不到**，但轮廓是完好的——
所以量轮廓比读标注更可靠。

### 7.4 分类要写进代码，不要写进注释

```python
BEAM_WEB = {"A-A": 0.257, "B-B": 0.258, "C-C": 0.357, "D-D": 0.604, "E-E": 0.594}
BEAM_BF  = {"A-A": 0.604, "B-B": 0.604, "C-C": 0.604, "D-D": 0.604, "E-E": 0.594}
ROLE_CUTS  = (0.50, 0.90)
ROLE_NAMES = ("梁身", "过渡", "填实")

def beam_role(k):
    r = BEAM_WEB[k] / BEAM_BF[k]
    for cut, name in zip(ROLE_CUTS, ROLE_NAMES):
        if r < cut: return name
    return ROLE_NAMES[-1]

BEAM_BODY = tuple(k for k in BEAM_AREAS if beam_role(k) == "梁身")   # 不是白名单
```

写成 `BEAM_BODY = ("A-A","B-B")` 再配一句注释，等于把人工结论冻进代码：
**改图纸、加剖面时它不会自动跟着变，而闸门会继续绿灯。**

### 7.5 两条交叉验证

分类（按腹板宽）与求积（按轮廓面积）是**两个独立测量**，必须同向：

1. `梁身断面数` —— 必须等于预期个数（本桥 2）。分类器失效会立刻在此暴露。
2. `面积随填实程度单调递增` —— 梁身组最小面积 ≤ 过渡组 ≤ 填实组。
   若分类判反了（把填实段归成梁身），面积顺序立刻矛盾。

**故障注入验证**（`test_gate.py` 第 7 条）：把腹板宽全量成同一值
（模拟"在翼缘高度处量，5 个剖面看起来都一样"），闸门同时报出
`梁身断面数 5≠2` 与 `离散度 1.72`，且复现出 v1 那个 0.948 均值。
