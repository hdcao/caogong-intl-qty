# 计算规则手册：扣减 / 加项 / 几何 / 钢筋（Calculation Rules）

**什么时候读**：准备算任何一个量之前。本文件是"读图结果"与"落表数值"之间唯一的计算契约。

> 一句话立场：**没有规则的数不许落表。** 每一个量都必须能说出——按哪条规则、代哪个式子、
> 输了哪些输入、扣了什么、没扣什么。说不全的，挂待核（fail-closed），不许给一个数充数。

单位解释以项目批准的计量规则和单位别名注册表为准。`m³`/`M3`、`m²`/`M2`、`LM`、`t`、`EA`/`nr` 等常见写法按本技能包单位核心解析；`CM` 属歧义代码，**不得全局默认等于 m³**。只有项目合同/BOQ明文定义其含义，并在 `unit_alias_registry.json` 中记录适用范围、合同来源条款、审批人和审批日期后，才可按该项目解析。示例默认使用 `M3`，以避免把单位约定误当成通用标准。
**换算只在落表时做一次**，中间计算全程保留全精度，禁止边算边四舍五入。

## 0. 六条硬规矩（本技能包的，优先于任何通用规则）

| # | 规矩 | 落到计算上的动作 |
|---|---|---|
| 1 | **口径二维登记** | 每个量同时标**范围口径**（全桥/单幅/两侧/每跨/每根/每延米/总计）与**证据强度**（图纸确认/推算/估算/待核）。缺任何一个维度，这一行不许进表。 |
| 2 | **绘图员负责算量** | 读数责任人 = 建模/绘图的人；复核人只能复核，**不能代填**。复核人改了数却不改签名栏，即成为新责任人。 |
| 3 | **读数四问** | 下笔前必须能答：① 在哪（图号+图面区域）② 什么方向（纵/横/竖/斜）③ 谁的什么属性（构件名+属性）④ 是不是我问的。答不全不许落账。 |
| 4 | **规范抠原文** | 引用规范必须抄原文条款号+原文措辞，**不引用二手转述**。实测事故：NOTE 写"嵌岩深度：软弱岩≥1.5 m / 完整岩≥0.5 m"，被转述成"桩长不小于 20 m"，据此填的桩长全错。 |
| 5 | **量纲三重自洽** | 单位列 ↔ 口径声明文本 ↔ 计算式，三处必须同一个量纲。A02 事故：单位列写 `SM`（面积），口径声明写"回图裁决 3252 m³"（体积），躺了两轮。**唯一防线是跨列比对**（G-DW）。 |
| 6 | **不可静默默认** | 缺值一律 fail-closed（0 或 `missing`），不许 `x or 1`、不许"当上一段"、不许"按经验"。确需默认的，默认值必须写进 `assumptions` 台账并挂在交付物里。 |

## 1. 扣减规则

### 1.1 线性工程量必须先扣结构物长度（最高频的重复计量）

凡沿**路线**计量的线性项（路面各层、标线、护栏、中央分隔带、排水沟、电缆沟），
其计量长度不等于路线长：

```
计量长度 = 路线长 − Σ桥长 − Σ涵洞/通道已单列段 − Σ其他已单独计量段
```

实测教训：路面/标线/护栏按路线全长算，桥长 191 m 未扣，而桥面铺装已单列 → **重复计量**。
判据很简单：**只要这个构造在桥上"另有单列项"，路线线性量就必须把桥长减掉**。
核减清单要逐座列，不许给一个"大概扣了"的总数。

### 1.2 按构件的扣减表（默认值；项目规则优先）

阈值是通行默认值（NRM2 / POMI / SMM7 口径），**CESMM4 与美标项目不同，必须先读项目计量说明**。

| 构件 | 毛量基准 | 扣 | 不扣 | 加项/并入 |
|---|---|---|---|---|
| 混凝土（墙/柱/梁/板） | 净体积 | 空洞 > 0.5 m³；洞口 > 0.5 m² × 厚 | 钢筋、埋件 < 阈值 | 规则含则并入附壁墩/路缘石 |
| 模板 | 展开面积 | 洞口 > 0.5 m² | 钢筋、甩筋、< 0.1 m² 小孔 | — |
| 砌体墙 | 净面积 | 洞口 > 0.5 m² | 洞口 ≤ 0.5 m² 合计 | 壁柱按规则；过梁单列 |
| 抹灰 / 饰面 | 净面积 | 洞口 > 0.5 m² | 洞口 ≤ 0.5 m² | 阴角/收边按周长计 |
| 楼地面面层 | 净面积 | 设备基础、管沟 > 0.5 m² | 柱/管 ≤ 0.5 m² | 门槛、窗台按规则 |
| 屋面 / 防水 / 保温 | 展开（含上翻）面积 | 采光洞、洞口 > 0.5 m² | — | 上翻、檐口、搭接缝 |
| **路面各层（每层）** | 平面面积 | **结构物长度**（见 §1.1） | — | **每层取自己的宽度**，见 §1.3 |
| 土工布 / 格栅 / 膜 | 平面面积 × 道数 | — | — | 大样画上下各一层就算两层，写 `layers` 并显式 `× n` |
| 填方 | 净体积 | 既有结构物、既有管线 | 树根等 | **只在开挖侧计松散系数** |
| 开挖 | 净体积 | — | — | 工作面、边坡按规则；外运乘松散系数 |
| 涂装 | 净面积 | 洞口 > 0.5 m² | — | — |

**两条绝对禁止**：
① **禁止从混凝土体积里扣钢筋**（钢筋另列，体积按外轮廓净尺寸）；
② **禁止乘百分比"损耗"**——损耗是采购/组价概念，不是计量概念，除非项目规则白纸黑字写了。

### 1.3 分层构造：一个宽度套所有层就是错

路面、防水、保温、土工合成材料这类"层叠构造"，失败方式只有三种：

| 失败 | 症状 | 规则 |
|---|---|---|
| 一个层宽套所有层 | 磨耗层/基层/底基层面积**完全相同** | 每层宽度各从自己的**尺寸链**读，存入该层的 `W` |
| 给构造层一个总厚度 | 扣减层只有一个拍脑袋的数（如 1.4 m） | 按**大样逐层累加**（如 0.6 + 0.2 + 2 × 土工布），`inputs` 必须列全每层 |
| 漏层数 | 大样画了上下两层土工布，只算一层 | `layers`/`courses` 进 `inputs`，算式里写 `× n` |

实测：**凭印象给的扣减总数约为逐层累加的 2 倍**。判据——不同层宽的结构层，
面积**应该**不同；几层算出来一模一样，不是巧合，是错（P11）。

### 1.4 边界归属写死（左闭右开）

相邻分区/分段共享一条边界，归属必须先约定（本项目统一 `[起点, 终点)` 左闭右开）并全程一致。
否则边界那一刀被两侧各算一次。同理，**扣减必须逐段归位后再求和**——
实测填方分段明细 3,900,091 vs 合计 3,717,537，差的 182,555 就是扣减没按段归位。
验收断言：`Σ分段 == 合计`，且 `Σ分段长 == 声明总长`。

**区间查询 fail-closed**：桩号落在所有分段之外时是**错误**，
不许静默兜底到"最后一段"或"最近一段"——那会让剩下全部桩号按错误的参数计价。

### 1.5 土方：必须算边坡，符号先定死

- 边坡率按**土质/岩性分区**取值，不许全线一个坡率。
- 断面一律按梯形/多边形成型积分，不许拿矩形断面糊。实测 4,729,499 m³ 填方全靠边坡积分。
- 用**独立数值积分**复核断面法，差异 > 1% 说明坡率或分区错了。
- **符号约定（写进交付物）**：`设计完成面 − 原地面`，**正为填、负为挖**。反号是最便宜也最贵的错。

## 2. 加项与不扣项

| 情形 | 处理 |
|---|---|
| 小于阈值的洞口/孔洞 | **不扣**（标准明文） |
| 钢筋、埋件、甩筋 | **不扣**混凝土体积 |
| 附壁墩、牛腿、路缘石 | 规则说并入才并入，否则单列；并入时写清 `merge` 依据 |
| 模板上翻、檐口、泛水 | 按展开面积**加**，不是按投影 |
| 开挖工作面、边坡 | 按规则**加** |
| 外运弃土 | 净体积 × 松散系数**加**；运距单列 |
| 损耗/搭接/损耗率 | 只有项目规则写明才计，否则不进入量 |
| 已在别处单列的构造 | **从本项扣除**（见 §1.1） |

**加项也要带出处**。加项和扣减一样必须有规则依据和阈值，不许"感觉应该加"。

## 3. 几何公式

输入一律先归一到米。

| 量 | 形状 | 公式 |
|---|---|---|
| 长度 | 线形 / 管线 | Σ 分段长（默认**中心线**，规则说周长才用周长） |
| 面积 | 板 / 面层 | 长 × 宽（净尺寸）；**斜交修正见下** |
| 展开面积 | 屋面 / 防水 | 面积 + Σ（上翻高 × 长） |
| 体积 | 棱柱 | 长 × 宽 × 高 |
| 体积 | 板 | 面积 × 厚 |
| 体积 | 圆柱 | π/4 × d² × h |
| 重量 | 型钢 / 钢筋 | 长 × 单位重 × 根数 |
| 个数 | 点状 | Σ 计数（**去重 block 引用**） |
| 展开面积 | 风管 | 2×(宽+高) × 长（+ 管件当量） |
| 中心线 | 墙 / 面层 | 厚度中线；`中线长 = 毛长 − Σ端部偏移`，偏移 = 半厚 |
| 投影面积 | 坡面 | 规则说"投影"时才用 |

**斜交修正**：`展开(斜交) = 投影 / cos θ`；已知坡比时 `cosθ = 平距/√(平距²+高差²)`。
斜交桥必须先声明桥长是**沿桥轴结构长**还是**沿路线路线长**，
两者差 `1/cos θ`（斜交 77° 时差 4.4 倍量级），声明写死进 Scope。

**个数绝不可隐含**：`count` 类（或任何读 `count` 的式子）必须显式给 `geometry.count`。
`0` 是合法值（已登记的占位），原样保留；绝不写 `x or 1`——它把 `None` 和 `0` 一起变成 1。
杆/灯具/基础/接地极/手孔井是最高危组，因为 1 永远像个合理答案。

## 4. 钢筋

### 4.1 取值优先级（从上到下，不许跳级）

1. **有配筋图 / BBS（钢筋表）→ 直读**。按表计量，再用"根数 × 间距 vs 几何"反向抽查；
   表在就不要从头推。
2. 有设计说明给出的 **kg/m³ 含量 → 用说明值**，并写明出处（说明编号 + 条款）。
3. **都没有 → 含钢率法**，但它是**推定**不是计量（见 §4.3）。

实测反例：支座垫石钢筋按 110 kg/m³ 反推得 3.3 t，业主钢筋表 11.1 t，**差 3.4 倍**。

### 4.2 单位重（ρ = 7850 kg/m³，`mass/m = ρ × π/4 × d²`）

| Ø (mm) | 6 | 8 | 10 | 12 | 16 | 20 | 25 | 32 | 40 |
|---|---|---|---|---|---|---|---|---|---|
| kg/m | 0.222 | 0.395 | 0.617 | 0.888 | 1.579 | 2.466 | 3.854 | 6.313 | 9.865 |

### 4.3 含钢率法是「推定」，不是「量」

用含钢率算出的钢筋量必须满足三条，缺一条不许进交付值：

1. **写明来源**：哪个规范条款 / 哪份市场数据，抄原文，不写"经验值 90 kg/m³"。
2. **挂 RFI 编号**，并登记敞口：若被推翻的处置（回算哪几行、谁确认、什么时候）。
3. **单独分层**（推定层），可整层剔除、不与直读行混排；口径列必须带"推定"字样，
   否则 G-A 报红。

推定层只把**已实测的混凝土量**换算成已定价子目，**不新增实物**。

### 4.4 下料长度与计量净长：**两者不是一回事**（v2.1 修订）

**计量重量 = Σ(图示净长 × 根数 × 单位重)**——搭接、定尺余料、垫铁**不另计**，
含在单价里（NRM2 / CESMM4 / POMI 的通行口径；只有 POMI 等少数标准把搭接单列
"extra over for laps"，须合同前言明文）。

下面的 `cut_length` 是**下料长度**，只用于 BBS 复核与组价，**不得直接当作计量重量**。
此前本节把"下料长"当作计重量，与 §2 的"禁止乘损耗"自相矛盾：
Ø25 定尺 12 m、搭接 40d，每 12 m 一次就是 +8.3%，一个 500 t 的梁体凭空多 25~40 t。

```
cut_length = 净跨 + 锚固 + 搭接 + 弯钩 − 扣减
```

| 项 | 规则 |
|---|---|
| 锚固 | 按设计依据读：EC2 `l_b,rqd = (Ø/4)·(σ_sd/f_bd)`；ACI `l_d = (f_y·ψ_t·ψ_e/(1.1·λ·√f'_c))·d_b`。**从设计依据里读公式，不许自己编** |
| 搭接 | `l_0 = α·l_b`（α 按搭接百分比、错开率、约束条件取）；ACI 按搭接等级 1.0/1.3/1.7 |
| 弯钩 | 90° 弯钩 ≈ 0.5·Ø；135° ≈ 0.75·Ø；180° 直段 4·Ø（最小）+ 弯曲调整。用设计的标准 |
| 保护层 | 按暴露等级取名义保护层；算箍筋下料时扣保护层 |
| 根数 | `n = floor(有效宽 / 间距) + 1`；**有钢筋表时以表为准** |
| 箍筋 | 各加密区/非加密区分别 `n = floor(区长/间距)`；长度 = 周长 + 2×弯钩延长 |
| 汇总（下料） | `下料总重 = Σ(下料长 × 根数 × 单位重)`，仅供 BBS 复核与组价 |
| 汇总（计量） | `计量重量 = Σ(图示净长 × 根数 × 单位重)`，**搭接/余料不另计**；按 Ø + 牌号 + 构件分组，kg 取整 |

## 5. 机电管线

电缆/管道/桥架/风管按**中心线长度**计量，按系统、按规格/材质/等级分列。

- **路由长度**取中心线节点间距离；管件是否另计看规则（多数情况管件单列或"随管敷设"）。
- **竖向段与下引段必须显式加**——这是最常被漏掉的量。
  `cable_length = 路由长 + 竖向长 + 下引长 + 端接预留`。
- **芯数**：只有当标准按"导体长度"计量（单芯）时才 × 芯数；多芯按"电缆长度"计。先查规则。
- **裕度**（波形/备用，常见 +2.5~5%）只在项目规则写了才加，并记进 `inputs`。
- 风管按**周长** `2×(W+H) × 长` 计展开面积，除非规则说含管件表面积。
- 管件/设备/支吊架按 `nr` 计；支吊架**按间距推算时必须标出所假定的间距**（这是假设不是图读）。
- **陪随项**：接地导体 ECC 与主缆**等长**，按 1:1 编排并做比率断言（实测整项漏 43 km）。

## 6. 措施项目

措施项目取决于**施工工法与工期**，不是图纸。没有工法说明或用户书面确认，**不许给数**。

| 项 | 依赖 | 计量 |
|---|---|---|
| 模板 / 支架 | 被支撑构件几何 | 展开面积 |
| 脚手架 | 立面/高度/工期 | 面积或体积；室内外分开；计价的要注明工期 |
| 降水 | 地下水位 / 工期 | 工期（周）或合计；所假定工期必须写来源 |
| 弃土外运 | 弃方体积 / 运距 | 净体积 × 松散系数；运距单列 |

全部措施项 `source = method`，进假设台账，**不许静默推定工期**。

## 7. 常见错误与防护

| 现象（可检索） | 为什么会错 | 防护 |
|---|---|---|
| 路面/标线按路线全长算，桥长没扣 | 桥上那一段已在桥梁分部单列 → 重复计量 | `计量长度 = 路线长 − Σ桥长 − Σ已单列段`；逐座列核减清单 |
| 各结构层面积完全相同 | 一个层宽套了所有层 | 每层从自己的尺寸链取 `W`；面积相同即缺陷 |
| 扣减层凭印象给总数 | 没按大样逐层累加 | 逐层列、逐层加；实测凭印象值约为累加值 2 倍 |
| 填方按矩形断面算 | 没算边坡 | 边坡率按土质/岩性分区；独立积分复核，差 <1% |
| 边界那一刀算了两遍 | 相邻分区边界没定归属 | 左闭右开写死，全程一致 |
| 填挖符号反了 | 没定符号约定 | 约定"设计完成面 − 原地面，正为填"并写进交付物 |
| 分段之和 ≠ 合计 | 扣减没逐段归位 | 逐段归位后求和；断言 `Σ分段 == 合计` |
| 桩号落在分段外却照样出数 | 静默兜底到最后一段 | fail-closed 报错，不许兜底 |
| 钢筋用含钢率反推 | 有表不用，用了推定还当实测量 | 直读优先；推定必须写来源 + 挂 RFI + 单独分层 |
| 支座/伸缩缝按"幅×跨×片×端"推算 | 推导式不是证据 | 直读专用表（实测推算 234 vs 直读 260） |
| 跨分部项串味（道砟计入桥梁） | 没先定分部 owner | 先定 owner 再定量；易混项在 Scope 点名 |
| 单位列与口径声明量纲矛盾 | 每道门禁只看自己那一列 | 单位列 ↔ 口径文本 ↔ 计算式三处跨列对拍（G-DW） |
| 某个量恰好是 1，而你从没写过 1 | `x or 1` 兜底 | 缺值一律 fail-closed，`count` 显式给 |
| 加了"损耗 5%" | 损耗不是计量概念 | 项目规则没写就不加 |
