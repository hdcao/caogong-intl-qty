# 无文本层矢量图取证（Vector Drawing Forensics）

**加载时机**：`extract_dwg_vector.py --list` 显示 `text=0` 且无图片（`scanned=False`），
**或者** `text>0` 但图元数量极大（如本项目 p3：text=10382、图元 61 万）——
后者是**部分转曲**：文字层只有跨号/标高/图名，尺寸标注仍是轮廓线。
此时**不是二选一**：文本层能直取的就直取，取不到的部分用本文的方法补。

```bash
python scripts/extract_dwg_vector.py <图>.pdf --list      # 先看文字层有多少
python scripts/vector_forensics.py probe <图>.pdf --out out/probe.json --page 3
```
（`--out` 给**文件名**；给目录会报 Invalid argument。）

> **立场：先榨干矢量，再渲染，最后才考虑 OCR。**
> 几何本身是确定的：填充色、图元尺寸、线段角度、符号重复间距——
> 这些都可直接统计，比读图可靠，也比 OCR 便宜。
>
> 提高渲染倍数或反复 OCR 都救不回来——**转曲后根本没有字符层。**

---

## 1. 判型矩阵（先判型，再选技法）

| `text` | `scanned` | 页面性质 | 首选路线 |
|---|---|---|---|
| > 0 | False | 原生矢量 + **完整**文字层 | **文本层解析**（最快最准） |
| > 0 | False | 原生矢量 + **残缺**文字层（部分转曲，图元极多） | **文本层直取 + 本文方法补缺口** |
| > 0 | True | 扫描件 + OCR 层 | 原生 dpi 切块；OCR 仅作检索辅助 |
| 0 | True | 纯扫描栅格 | 原生 dpi 切块 + 二值化 |
| **0** | **False** | **文字转曲矢量** | **本文**：probe → 矢量统计 → 尺寸链闭合 → 渲染切块 → OCR（仅辅助） |

```bash
python scripts/extract_dwg_vector.py <图>.pdf --list
python scripts/vector_forensics.py probe <图>.pdf --out out/probe.json --page 3
```

`probe` 输出每页：页面尺寸、`/Rotate`、文本长度、字体数、`get_drawings()` 图元数、
**填充色直方图 / 矩形尺寸直方图 / 线段角度直方图**。
**这三张直方图就是读图的地图。**

---

## 2. 五件套技法

### T1 高倍渲染 + 切块（不是越高越好）

- 渲染倍数按页面尺寸与内容密度取 **3~7×**：A3 小图 3× 即可，A0 大图上的 1:30 细部要 6~7×
- **必须切块**：整图缩略到 1600px 后，尺寸数字全部糊掉
- 切成 3×3 或按内容区裁（`--crop` 用页面比例，便于记录 provenance）
- **判读顺序**：图签 → 图名 → 图例 → 尺寸链 → 断面 → 明细表

---

### T2 旋转回正（A0 竖排图的头号坑）

- 旋转角从页面 `/Rotate` 取，**不要按幅面猜**
- PDF 渲染坐标与图像坐标 y 轴相反，`ROTATE_90` / `ROTATE_270` **极易搞反**
- **用图签位置校验方向**：转对了图签就在右下角且文字正立
- 旋转图上的尺寸链**先转正再读**，不要练"倒着读字"

---

### T3 矢量图元提取（比渲染更可靠）

```python
for dr in page.get_drawings():
    fill = dr.get("fill"); stroke = dr.get("stroke"); r = dr["rect"]
    for it in dr["items"]:            # ("l", p1, p2) / ("re", rect) / ("c", ...)
        ...
```

| 直方图 | 用途 | 实测案例 |
|---|---|---|
| **填充色 `fill`** | 按颜色分离图元类别 | 灯头 `fill=(1,0,1)`；手孔 `(0,0,1)`；人孔 `(1,0,0)` |
| **矩形尺寸** | 区分符号与线条碎块 | 灯头方块 2.0/3.0/3.8 pt；虚线短划长宽比 >3 |
| **线段角度** | 判构件走向、找主要方向 | 梁线为竖向虚线；尺寸线水平 |

---

### T4 颜色 + 尺寸过滤 + 空间聚类计数

流程（比目测可靠，且**可复现**）：

1. 按 `fill == 目标色` 取全部图元矩形
2. **方形/尺寸过滤**：`wmin≤w≤wmax`、`hmin≤h≤hmax`、`aspect_min≤w/h≤aspect_max`
3. 取每个矩形**中心点**，空间聚类（并查集 / KDTree，阈值 `tol`）
4. 输出**"每簇块数"直方图** —— 即"每个符号含几个计量对象"

**`tol` 标定是成败关键（实测踩坑）**：

| tol | 现象 |
|---|---|
| 太小（2.6 pt） | 同一符号内的块没聚住 → 符号被拆成若干"1 头" → **计数虚高** |
| 太大 | 相邻符号合并 → **计数偏低** |
| **标定方法** | 先量「符号内相邻块中心距」和「相邻符号中心距」，**取二者之间** |

```bash
python scripts/vector_forensics.py symbols <图>.pdf \
  --color 1,0,1 --size 1.9-4.5 --aspect 0.75-1.33 --tol 6 --out out/
# -> {"total_symbols": 21, "hist": {"1": 6, "2": 3, "3": 2, "6": 1}}
```

> **图例区污染计数**：每页右栏图例里也画着同样的符号。
> 要么裁掉图例区再统计，要么减去图例常数，**并把做法写进 provenance**。

---

### T5 尺寸链闭合反证（最有力的交叉验证）

**读到的每一组尺寸都要能闭合。闭合不了就是判读错了，不是"图纸矛盾"。**

```bash
# 分段求和
python scripts/vector_forensics.py chain --total 19960 --parts 1630,1630,...
# 均分反算：N = (L总 − 2×边距 − 单件宽) / 间距 + 1
python scripts/vector_forensics.py chain --total 23610 --equal 8 --edge 1194 --unit 1640
```

**闭合类型**：

| 类型 | 实测式 |
|---|---|
| 分段求和 | `19960 = 11 × 1630` → 12 榀梁 |
| 均分反算 | `(23610 − 2×1194 − 1640)/2448 + 1 = 9` 榀/幅（与 "8 EQUAL SPACES" 一致） |
| 标高/厚度 | 箱涵总高 `2400 = 450 + 1500 + 450` |
| 高程链 | `FSR − 承台底 = 2.20 + 6.00 + 2.00(墩) + 0.283 + 2.00 + 0.30 + 0.80` |

**★ 凡是要靠"数数"得到的量（梁、桩、灯杆、涵孔），
都必须有一条尺寸链或一张专用表兜底。只用视觉数数的，一律降为 `medium` 并挂 RFI。**

**反证不通时的处理顺序**：
```
重读图（多半是漏看一段尺寸链） → 换一张图交叉 → 标 conflict 挂 RFI
```
**不许取中间值"凑"。**

## 3. 比例尺标定：双校准法（本项目核心沉淀）

**单一次标定出错无从发现。必须找到两个已知尺寸互相印证。**

### 3.1 实测案例（图册 23041-OVA-29-V0，3/3 张 page 2，C.1 台区立面）

```
① 承台填充矩形   108.6 pt ÷ 9.58 m = 11.33 pt/m
② 承台厚度        25.0 pt ÷ 2.20 m = 11.36 pt/m
   → 互证，差 0.3%（<2% 容差）→ 采信 11.33 pt/m
```

若两个值差超过 **2%**，说明**量错了对象**——量的不是同一构件，或含了箭头外延。
必须重找参照。

### 3.2 参照物可靠度排序

| 序 | 参照 | 说明 |
|---|---|---|
| 1 | **填充/剖面线矩形** | 实体构件，边界确定，最可靠 |
| 2 | 标注尺寸线 | **含箭头外延，须扣除** |
| 3 | 图签比例栏文字 | 需有文本层；且只给名义比例 |
| 4 | 同图册其他图的同构件 | 交叉验证用 |

### 3.3 本项目已标定比例尺（可复用）

| 图 / 区域 | 比例尺 | 校准参照 |
|---|---|---|
| 3/3 张 page 2 · C.1 台区立面 | **11.33 pt/m** | 承台矩形 108.6pt/9.58m + 厚度 25.0pt/2.20m |
| CULEE 01/02 + PILES（ECH 1/100） | ≈27.5~28.2 pt/m | 承台/桩径 |
| Coupe A-A~E-E（1/15） | 189.1 pt/m | 断面尺寸 |
| DETAIL DALLE（1/25） | 113.4 pt/m | 板厚 |
| 梁立面 VUE EN PLAN（1/40） | 70.9 pt/m | 梁间距 |

## 4. 实测案例：C.1 台区立面读数落账

**轴线**：x = 661.0 pt；**比例尺**：11.33 pt/m

| 读数 | 图面位置 | 方向 | 值 |
|---|---|---|---|
| 承台范围 | 填充矩形 (592.0,391.5)-(700.6,416.5) | 纵向 | 轴 −6.09 → 轴 +3.49（中心偏轴 **−1.30**） |
| 台身墙顶 | 紫色结构线顶 | 纵向 | 轴 −2.59 → 轴 −1.60（**1.00**） |
| 台身墙底 | 紫色结构线底 | 纵向 | 轴 −6.59 → 轴 −1.09（**5.50**） |
| 台身高 | 墙顶 → 墙底 | 竖向 | **6.00** |
| 前脸收分 | 轴 −1.60 → 轴 −1.09 | 纵向 | **0.50** |
| 背面斜率 | 轴 −2.59 → 轴 −6.59 | 纵向 | **4.00** |

**闭环校验**：`1.00(顶) + 4.00(背面水平) + 0.50(前脸收分) = 5.50(底)` ✓
**均值厚** = (1.00 + 5.50) / 2 = **3.25**
**竖向链**：FSR(y≈285.7) → 承台顶 391.5 → 承台底 416.5，误差 **<0.6 pt** ✓

> **C.2 为 C.1 的镜像**：承台中心偏轴 **+1.30**。
> **未计价新发现**：台区立面另见 1.00 厚前墙/梁座构造（黑填多边形，约 8.63 m 高），
> I03=503.10 未含；若判为独立承重墙则 **+≈223 CM**，已挂 APD 澄清。

```json
"provenance": {
  "sheet": "23041-OVA-29-V0/3-3",
  "drawing_location": "C.1 台区立面 x642~654, y293~392",
  "direction": "纵向",
  "object": "桥台台身",
  "attribute": "楔形 顶1.00/底5.50/高6.00",
  "method": "chain_derived",
  "evidence_word": "推算",
  "scale": {"pt_per_m": 11.33,
            "refs": ["承台矩形108.6pt/9.58m", "承台厚度25.0pt/2.20m"],
            "residual_pct": 0.3},
  "chain_closure": "1.00 + 4.00 + 0.50 = 5.50",
  "readings": ["1.00", "5.50", "6.00"],
  "render": "render/c1_elev_full.png",
  "drafter": "曹工"
}
```

**`method` 与 `scale` 字段必须写**——审图人看到 `render_read_est` 就知道要重点复核，
看到 `schedule_direct` 才可直接采信。
**没有 `method` 的读数 = 没有出处，不许进入合计。**

## 6. 停止条件

| 情况 | 处理 |
|---|---|
| 矢量聚类 tol 无论如何标定都会并掉相邻符号 | 改用尺寸链闭合（T5）；仍数不出就承认，登记为待定，**不许用"面积 × 密度"反推** |
| 尺寸链闭合不上，换图交叉也不上 | 标 `conflict`，**两条都留**，挂 RFI |
| 同一构件在两张图上断面不同 | 先确认是否"逐座设计"，**不要挑一个** |
| 需要 OCR 而环境没有 OCR | 走矢量统计 + 渲染目测**双通道互相印证**，provenance 写明 `ocr_unavailable` |
| 图上完全没有尺寸，也没有可标定比例尺的参照 | 挂 RFI，**禁止按经验值填数** |
