# 迭代修订轮次协议（Revision Rounds）

**加载时机**：拿到第三方对比报告、审核意见，或用户要求"按对比结果里我的不足去改"。

> **实战来源**：沙特 SPARK 东绕城公路 EPR 项目 V4→V7 四轮审核；
> 阿尔及利亚 ANESRIF 铁路桥项目三方工程量裁决（PK295+206 裁决报告）。
>
> 每一轮都发现**上一轮自以为已经解决的问题其实是错的**。
> 所以本文件的核心不是"怎么改数"，而是
> **怎么让每一轮的改动可追溯、可回退、可审计**。

---

## 1. 轮的划分：一次只打一个分部

| 轮次 | 聚焦 | 发现类型（SPARK 实测） |
|---|---|---|
| V4→V5 | 全表闭包 + 涵洞 | 汇总表与明细表矛盾、填方分段不闭合、涵洞附属整组漏 |
| V5→V6 | **桥2** | 结构体系判错（I 梁组合 ≠ T 梁）、桩数差 40%、桥台整项漏 |
| V6→V7 | **照明** | 杆型口径错、灯具数≠杆数、基础量差 3.9 倍、箱变/桥下照明/接地整组漏 |

**规则**：一轮一个分部。混着改会让两类错误**互相掩盖**——
"总量差不多"会让人以为没问题，其实是桥2 多了、照明少了正好抵消。

---

## 2. 每轮的五步

```
1. 定边界   —— 本轮改哪些分部、哪些不改（如"3D 模型不更新"），先写下来
2. 回图取证 —— 不靠记忆与上一版结论，回到图纸取证据链（见 §3）
3. 分级     —— A 量级 / B 漏项 / C 量差 / D 规范，先 A 后 C
4. 修订     —— 改生成器，不改产物；同步四件套
5. 回读断言 —— 结构完整性 + 闭合性复核（见 §6）
```

**顺序不能反**：先解决 A 类（结构体系、量级），再解决 B 类（漏项），最后才是 C 类（量差）。

> 参数算错是 10% 级误差；体系判错是 40% 级误差，**量差再多也补不回来**。

---

## 3. 取证：结论必须能被推翻

每一条修订都要有**可复现的证据链**，不接受"根据经验""通常做法"。

| 证据类型 | 强度 | 记法 |
|---|---|---|
| 专用表直读（支座表、桩位图、钢筋表、图例） | 最强 | `schedule_direct` + 图号 + 表内数字 |
| 尺寸链闭合 | 强 | `chain_derived` + 闭合式 |
| 矢量聚类计数 | 中 | `vector_cluster` + 参数（颜色/尺寸/tol） |
| 渲染估读 | 弱 | `render_read_est` + 图号 + 裁块区域 |
| 切块读字 | 中 | `render_read_text` + tile 坐标 + 字高 |
| 无依据 | **不可采信** | 挂 RFI，不填数 |

**推翻自己上一版结论时，要写明"上一版为什么错"**——
这比新值本身更有价值，它防止下一轮再犯。

> 示例写法：
> "V6 写『桥2 = 整体 T 梁 + 250 现浇板』。
> V7 修订依据 HA-035121-003 的 1:30 梁断面与 1:10 板座详图，
> 实为**预制预应力 I 梁 + 预制 PLANK + 现浇层**。
> V6 系沿用桥1 断面参数外推所致（P39）。"

> 本项目实例：
> "原 T01=7841.66 CM 系把 DEMI COUPE 上的**梁间距 1.28 当作梁宽**、
> 且**梁高误取 1.50** 双重错误所致；
> 实际 10 片/跨（DEMI COUPE 10 个等距 1.28 m 块 + 业主清单 6.05=130 U 双证），
> 断面 0.75 m²、梁高 2.00 → **3403.50 CM**。"

## 4. 四件套（每轮必须产出/更新）

### 4.1 修订对照表

| 列 | 说明 |
|---|---|
| 编号 | `V{n}-1`、`V{n}-2`…轮内连续 |
| 分部 | 照明 / 桥2 / 涵洞 |
| 原值 | 上一版的值（**含口径描述**） |
| 新值 | 本版的值（含口径描述） |
| 修订依据 | **图号 + 图面原文**（不是"经验""常规"） |
| 量差影响 | 增/减百分比 |

> **"增"和"减"的项必须分开列**。
> 实测：桥2 砼 +17% 而桩基 −40%，两条混在合计里会互相抵消，报价时看不出单项风险。

### 4.2 RFI 清单

- 编号**累积不重排**（R1…R26），跨轮次连续
- 已闭环的标记 `closed`，**不要删除**
- 每条写清：问题、当前暂取值、为什么需要澄清、优先级（高/中/低）
- **暂取值必须显式标注为"暂列/估算"**，口径列写 `估算`

### 4.3 审核发现清单（分级）

| 级 | 含义 | 例 |
|---|---|---|
| **A 量级** | 口径或量级错误，影响 >20% | 高杆基础当 12m 基础（差 3.9 倍）、双幅算成单幅 |
| **B 漏项** | 整组/整项缺失 | PS 箱变 17 座、桥下照明、ECC 43 km |
| **C 量差** | 口径对但数值差 | 4C×16 漏 100 m、面积 3900→3541.5 |
| **D 规范** | 编码/词汇/格式 | 编码重复、口径写"已计量" |

### 4.4 分部计算书

为该分部单开一张表：**证据链 + 断面正算过程（分块累加）+ 数量闭合验算 + 关键图证索引**。

> **计算书要让下一个接手的人不用重看图就能验算。**

## 5. 口径词汇表（两个维度，缺一不可）

### 维度一 · 证据强度（这个数哪来的）

| 词 | 含义 |
|---|---|
| **图纸确认** | 图面直接读得（尺寸链、专用表、图例、标注文字） |
| **推算** | 由几何/数量闭合关系导出，**式子已写在计算式列** |
| **估算** | 图面无依据，按规范或经验取值，**必须挂 RFI** |
| **待核** | 图面缺失且不拟取值，等业主/设计回复 |

### 维度二 · 范围口径（这个数覆盖多大范围）

全桥 / 单幅 / 双幅 / 两侧 / 单侧 / 每座 / 单座 / 每跨 / 每根 / 每延米 / 总计 / 合计 / 单件 / 全段

> 只写"全桥"不写"推算" → 知道量多大、不知道准不准。
> 只写"推算"不写"全桥" → 知道准不准、不知道算的是哪一段。
> **两个维度都要登记。**

### 禁用词（伪闭环）

**已计量 / 已确认 / 复核无误 / 无误 / 已核实 / 已复核 / 无问题**

这些词在交付物里读起来像闭环，实际上掩盖了未解决的问题。

## 6. 回读断言（改完必须回读）

| 断言 | 为什么 |
|---|---|
| **分部标题行完整性**：每个编码层级的父标题都存在 | 实测批量插删行把上一级分部标题吃掉，14 个细目成孤儿 |
| **受影响行数 == 预期行数** | 批量变换的前提要先确认，不是变完再验 |
| **分段之和 == 合计** | 填方分段曾差 182,555（扣减层没按段归位） |
| **A 表汇总 == B 表明细之和** | 箱涵 01 表 8,884 vs 04 表 6,316，差 40.7% |
| **零量行备注覆盖率 100%** | 0 量的废项没人看得出是漏还是无 |
| **只改生成器，不改产物** | 直接改 xlsx 会在下一轮重跑时被覆盖 |
| **单位列与口径声明量纲一致** | A02 单位 SM 而口径写 m³，躺了两轮没人发现 |

## 7. 版本协议

- 版本号**只进不退**：V4 → V5 → V6 → V7，旧版本**留档不删**（逐版 diff 要用）
- 每版交付说明：**本轮改了什么、改的依据、还剩哪些 RFI**
- 交付说明里要写**上一版的哪个结论被推翻了，以及为什么**
- 用户明确说"某件东西不更新"（如 3D 模型）时，写进本轮边界并遵守——
  **不要顺手"一起改了"**

---

## 8. 三方对比的正确用法

| 做法 | 说明 |
|---|---|
| ✅ 以**自己的不足**为纲逐条回图核 | 不辩解，也不靠挑别人的错来平衡 |
| ✅ 三方一致的项仍抽 3~5 个关键参数回图 | 一致 ≠ 正确 |
| ⚠️ **三方完全一致时要警惕共模错误** | 先比 `param_source`；同源的"全一致"是假通过 |
| ✅ 比数之前先建**编码桥**（我方码 ↔ 对方码） | 不可比（m³ vs m²、LM vs EA）就单列"口径不可比" |
| ✅ 逐版本 diff | 只看最新版会漏掉演进过程里的反复项 |

> **本项目实例**：三方裁决后图读混凝土 15,316.27 CM vs 回图裁决 15,306.9 CM，
> 差 **+0.06%**——收敛不等于正确，仍是把各自口径对齐后的结果。

---

## 9. 什么时候该停

| 情况 | 处理 |
|---|---|
| 关键尺寸图面无依据且没有可比规范 | 挂 RFI，**不要取中间值凑数** |
| 批量变换行数不符 | **先撤销，不要叠加修正** |
| 本轮发现推翻了上一轮的结构性结论 | 先回图确认新证据，再改；**一次只改一个体系结论**，改完重跑闭合 |
| 交叉复核判为同源假通过且无法回图重建参数 | 停下说明，不要硬推 |

停下时必须说明：**是哪一条停止条件** + **需要什么输入才能解除**。
