# 证据分档与覆盖率

> 回答一个问题：**凭什么说这份报价的底价是可靠的？**

## 一、分档只有三档

| 档 | 含义 | 判据 |
|---|---|---|
| **A 已回价** | 供应商实际报价 | 有供应商回函或回价单，口径可比 |
| **B 待询价占位** | 已发询价但未回，或我方自出的询价包 | 询价单在，但**我方出的询价包 ≠ 供应商回价** |
| **C 经验推导** | 无询价，按市场经验或规范推导 | 必须标注推导依据和市场价来源 |

**判定铁律**：凡备注写"非最终价/须以 RFQ 替换/暂估"的一律归 **B**，不得算已回价。
自己做的询价文件**不等于**供应商回价。

### 一之二 · 证据有两个维度，不许混为一谈（2.0.0 修订）

v1.x 只有一个"证据档 A/B/C"，但它实际上描述的是**价格成熟度**；
而 D2（工程量与图纸依据）需要的是**数量证据强度**。两者不是一回事，
混用会出现"价格有回价，但量是猜的"却被整体判为可信的荒谬结论。

| 维度 | 回答什么 | 取值 | 用在哪一维 |
|---|---|---|---|
| **价格成熟度**（A/B/C） | 这个**单价**哪来的 | A 已回价 / B 待询价占位 / C 经验推导 | D4 成本结构与组价口径 |
| **数量证据强度**（method） | 这个**量**怎么取出来的 | `schedule_direct` / `text_layer` / `chain_derived` / `vector_cluster` / `render_read_text` / `render_read_est`（v4.6.0 六档） | D2 工程量与图纸依据 |

**两条独立，都要登记**。任一条缺失 → 该行不具备双源印证资格。

**交叉规则**：
- 价格为 C 档（经验推导）**且** 数量证据为 `render_read_est`（无字可读的估读）→ 该行**整行降为估算**，
  必须挂 RFI，不得进入承诺总价。`render_read_text`（切块读到图面数字）按 medium 计，不受此条。
- 数量为 `schedule_direct` 或 `text_layer`，但价格为 C 档 → 量可信、价不可信，报价按"量定、价待询"处理。

## 二、覆盖率只认金额加权

**禁用**「询价文件数 ÷ 条目数」——一份 RFQ 覆盖几十个条目，用文件数算会严重低估。

**必须**按 `工程量 × 单价` 加权：

```
覆盖率_A = Σ(量×单价 | A档) / Σ(量×单价)
```

按条目数算的话，小项和亿元大项等权——一个 1 万的小项和一个 3亿的大项
在"条目数"里都算 1 条，结论毫无意义。

## 三、覆盖率低时的正确表述

**不要说"覆盖率偏低"**，要说清实际分档构成。实测案例：

> 直接费 357,962,451.75 = A **0 行 / 0 SAR / 0.00%**
> + B 3 行 / 3,864,700 SAR / 1.08%
> + C 140 行 / 354,097,751.75 SAR / 98.92%**

这个结果不是"覆盖率偏低"，是**"一行都没有"**。
前者听起来还可以补救，后者意味着**成本底价的证据等级整体不成立**——这是两个完全不同的结论。

## 四、置信度分账（硬规矩）

**模型置信度 ≠ 报价可信度。**

三维模型几何再准，也不能说成本可靠——回价没拿到之前，
禁止用"模型置信度 98%"来暗示"报价也很可靠"。

两个数必须分开报：
- **模型置信度**：几何与图面的一致程度（可由交叉复核支撑）
- **报价证据等级**：A/B/C 分档构成（由询价覆盖率决定）

在报告里并列这两个数时，**必须显式说明二者不构成互相支撑**。

## 五、每条量都要能回答

| 问题 | 不合格答案 |
|---|---|
| 这个数从哪来？ | "按经验" |
| 谁确认的？ | 没写 |
| 什么时候确认的？ | 没写 |
| 如果这个假设被推翻，处置是什么？ | 没写 |

合格格式：
> 含筋率法 90 kg/m³（来源：SBC 304 §R1.1.5），按承台 14582 CM + 桥台 14912 CM
> 计得265.4 MT，取 266 MT。**假设人**：***　**确认日期**：***
> **若被推翻**：若业主提供结构化设计图，须按配筋图重新统计，差异进变更。

**无"确认人+日期"的假设不进成本模型。**

## 六、敞口台账：每个未决项都要写清处置

| 项 | 依据类型 | 若被推翻的处置 |
|---|---|---|
| 桩长 24m | 规范推导（NOTE20 嵌岩约束 + Abqaiq 覆盖层上界） | 按实际桩底标高调整，超出部分按实结算 |
| 翼墙厚 1000mm | 惯例（MOT 桥台标准） | 按实际配筋调整 |
| 环氧涂层比例 40% | 惯例（SBC 未给强制比例） | 按实际涂层范围调整 |

**依据类型必须区分**：
- **图读**（有图号+图面位置）—— 最强
- **规范推导**（有条款号+推导链）—— 可复算
- **惯例/经验**（有市场来源）—— 最弱，须标注

**禁止**在台账里写"待澄清"却又不给处置——澄清通道关闭时，
一律按「图纸 > 规范 > 惯例」取值，并把假设和处置登记在案。
