# caogong-intl-qty · 曹工国际工程算量助手

**WorkBuddy Skill** ｜ 版本 **v4.6.5** ｜ 国际工程图纸算量、BOQ 核对、图纸版本影响分析与 2D / IFC 模型复核。

> 核心立场：**算量本身不难，难的是发现自己算错了。**
> 本技能的主要产出不是那个数字，而是**证明这个数字可信的过程**——取量前先确认项目规则与图纸基准，逐项追溯证据，再用 15 道质量门禁与执行凭证让"算错"和"口径错"在交付前自己暴露。

本仓库是 v4.6.5 发布包的**源码镜像**，219 个文件与 `caogong-intl-qty_v4.6.5.zip`、本机已安装副本逐字节一致；仅额外新增本 `README.md` 与 `.gitignore`（仓库级文件，不属于技能包）。

## 安装

完整依赖与自检命令见 `INSTALL.md`。

## v4.6.5 验收状态

本版为**独立第三方审核发现问题的全面整改版**，原 6 条致命项已全部消除并复测：

- 四组门禁自测：G-OFF **42/42**、G-RUN **14/14**、G-SRC **19/19**、Input Digest **15/15**
- 发布闸：`RELEASE SMOKE RESULT: 34/34 passed`、`SOURCE TREE UNCHANGED: True`、`rc=0`
- 审核致命项重放：自有验收脚本 **32/32**；审核方独立脚本 G-OFF **15/15**、G-RUN **8/8**
- 五类误报场景（完整桥梁 / 完整涵洞 / 圆管涵 / 扩大基础 / 刚构桥）全部 `rc=0`

关键机制：三态退出码 `0 通过 / 1 FAIL / 2 CANNOT_RUN`（**未核 ≠ 通过**）；
G-RUN 凭证用 HMAC-SHA256 签名并支持 `verify --recheck` 当场重跑；
G-OFF 的 PAIR 判据由"在场集合检查"反转为"`systems` 声明 ⇒ 应有项全集对照"。

> **HMAC 防护边界（勿误解）**：密钥与凭证同目录时自签可伪造，故同目录密钥一律判 FAIL，
> 密钥只取 `$GATE_RUN_KEY` 或 `~/.caogong/gate_run_key`。**不得表述为"不可伪造"**；
> 同机同用户下的恶意自欺需外部不可写证据源（CI 日志 / git / 第三方时间戳）兜底。

## 已知限制（整改后仍开放，如实记录）

1. **落地性**：15 道门禁人工准备约 40~85 人时，接近甚至超过算量本身工时，投标期难以执行；
   需为轻档定义可信最小集，或在 `SKILL.md` 明确适用场景。
2. **`PAIR-6C` 输出噪音**：极小项目可刷 15 行条件项 INFO，可能把 `RATIO-0「未校验」` 埋掉；
   下版本拟改 `[NOTE]` 独立前缀 + 尾部计数。
3. **无真实项目端到端验证**：现有全部验证均为构造夹具与回归自测，不等于项目级验证。
4. **法语状态码层级**（`PRO/DCE/DOE`）按阿尔及利亚实务推断，未核 NF P 02-001。
